        Source inspection and experimental scope

        Numbered Steps references historical commit d2a3e56: steps: [{title, text}], layout, optional loop and ariaLabel. Stacked, row and divided-list treatments retain their reading order and mobile stacking.

        Icon Grid uses the existing three/five-open presets: items: [{icon, title, description}], columns, layout, optional iconColors. This preview retains the open structure with line-and-fill artwork informed by the Model Codes experiment. Restrained cobalt, coral and jade accents live within the illustrations, not component identity colours.

        Flashcards use the three-up preset: title, columns, cards: [{icon, front, back}]. The two-column control keeps all three cards to test wrapping. Each card toggles independently, retains keyboard focus, exposes its pressed state and counts each explanation once. Viewed state persists when cards flip back or the column count changes. Reset is a review-only control.

        The original all-viewed completion trigger is represented here by local progress only; this experiment sends no Rise completion messages. No production exports, old repository changes, Web Awesome runtime or framework. Foundation variables supply new component styling. Note and Key Takeaway retain their existing CSS and content.

        Refinement: editorial numerals, line-and-fill icons and compact, content-sized Flashcards with longer example explanations. Existing foundation tokens supply spacing and surfaces; illustration colours come from DESIGN.md. No new foundation values or design rules.
